## Sobre o Repositório
Este repositório contém a resolução dos exercícios propostos nas páginas 27 a 30 do material da disciplina de Introdução à Programação (CPE). O objetivo é praticar as estruturas fundamentais da linguagem Python: entrada e saída de dados, tipagem, condicionais e estruturas de repetição.

## Estrutura dos Arquivos

* **01-fundamentos/:** Operações aritméticas básicas e manipulação de entrada e saída.
* **02-decisoes/:** Implementação de lógicas usando `if`, `elif` e `else`.
* **03-strings/:** Manipulação de textos, fatiamento (`slicing`) e estruturas de repetição `for`.
* **04-desafios/:** Exercícios de engenharia englobando o uso da biblioteca `math`.

## Como Executar
Para testar qualquer um dos programas, basta ter o Python instalado na máquina. Navegue até a pasta do arquivo e execute via terminal:
`python nome_do_arquivo.py`
